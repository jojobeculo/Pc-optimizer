FrameCore — informations importantes avant installation

FrameCore est un logiciel libre et gratuit (licence MIT) d'analyse et d'optimisation de Windows 11 pour le jeu.

Ce que fait l'installation :
  • copie l'application dans le dossier choisi (Program Files par défaut) ;
  • crée les raccourcis demandés et une entrée « Applications installées » pour la désinstallation ;
  • ne modifie AUCUN réglage de Windows, n'installe aucun pilote, aucun service, aucune tâche planifiée et aucun logiciel tiers.

Ce que fait l'application :
  • fonctionne sans droits administrateur pour l'analyse ; ne demande l'élévation (UAC) que pour appliquer une modification que vous avez validée ;
  • enregistre l'état exact de chaque réglage avant de le modifier et permet de tout restaurer (élément par élément ou en bloc) ;
  • propose de créer un point de restauration Windows avant les modifications ;
  • ne désactive jamais Microsoft Defender, le pare-feu, Windows Update, Secure Boot, le TPM ni la protection VBS/HVCI ;
  • ne collecte aucune donnée et n'envoie rien sur Internet sans votre accord explicite (aucune télémétrie).

Limites à connaître :
  • l'exécutable n'est pas signé numériquement (aucun certificat de signature n'a été fourni) : Windows SmartScreen peut afficher un avertissement « Éditeur inconnu » ;
  • les fonctions d'overclocking GPU s'appuient sur les interfaces officielles NVIDIA (NVML) et AMD (ADLX) ; tout overclocking comporte un risque d'instabilité. Le réglage CPU et les profils XMP/EXPO se font dans le BIOS : FrameCore fournit des conseils, il n'écrit jamais dans le BIOS ;
  • les gains de performances dépendent de votre configuration ; FrameCore les mesure au lieu de les promettre.

Vos données (profil matériel, sauvegardes, historique, benchmarks) sont stockées uniquement sur ce PC, dans %LOCALAPPDATA%\FrameCore. Elles ne font jamais partie de l'installateur.
